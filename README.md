This is a one-stop-shop website that you can find all events going on at Mount Mary University. This website features:
1. Campus events 
2. Local, non-campus events
3. Astrological events 
4. Resources that lead to:
    -Partiful, where you can make an event and send out invitations to your friends so they can rsvp.
    -The CWC, where you can talk to a councilor for free on campus.
